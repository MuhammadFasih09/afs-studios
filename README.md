# AFS Studio

AFS Studio aik web-based platform hai jo AI-powered text-to-image generation aur user personalization features provide karta hai. Project 3-member team ne collaboratively banaya hai.

## 📌 Project Overview

AFS Studio ka maqsad users ko aik secure login system, AI se images generate karne ki facility, aur unki profile/settings manage karne ka control dena hai — sab aik hi platform par.

## 👥 Team & Contributions

| Member | Contribution |
|--------|--------------|
| **Shayan** | Login Page — user authentication aur entry point ka design/functionality |
| **Ayan** | AI Text-to-Image Generator — text prompts se images generate karna, resolution selection ka functional feature |
| **Fasih** | Settings Section — theme switch, profile edit, aur generation history |

## ✨ Features

- 🔐 **Login Page** — secure user authentication
- 🎨 **AI Text-to-Image Generator** — text prompt se image generate karna
- 📐 **Resolution Control** — generated image ki resolution select karne ka option
- ⚙️ **Settings**
  - Theme switch (light/dark ya custom themes)
  - Profile edit
  - Generation history dekhne ka feature
